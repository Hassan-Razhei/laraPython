# سياسة الأمان والحماية في LaraPython

تتبع المنظومة ضوابط أمنية صارمة لعزل وتشغيل العمليات البرمجية:

## 1. منع حقن الأوامر (Command Injection Prevention)
- تنفيذ العمليات يتم حصراً عبر مصفوفة وسائط صريحة (`Process::run([$python, $script, ...])`).
- حظر دمج نصوص الأوامر مع مدخلات المستخدم العشوائية في قشرة النظام (Shell).

## 2. منع اختراق المسارات (Path Traversal Protection)
- التحقق الإلزامي من عدم احتواء اسم السكربت على مقاطع تراجع (`../` أو `..\`).
- التأكد من بقاء المسار المستهدف ضمن المجلد المسموح به (`config('python.scripts_path')`).
- رفض أي ملف لا يحمل الامتداد `.py`.

## 3. حماية بيانات الاعتماد (Credentials Safety)
- تمرير البيانات والوسائط الحساسة عبر القنوات المشفرة أو مجاري البيانات، وتجنب الوسائط الصريحة التي تظهر في جدول العمليات (`ps`).
- حجب تفاصيل مسارات النظام الحساسة أو الـ Tracebacks عن الاستجابات الموجهة للمستخدم النهائي.
